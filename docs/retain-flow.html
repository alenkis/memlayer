UPDATE reconciliation
On UPDATE: the memory content changes, so entity mentions may change too. The pipeline removes old mention edges for that memory and creates new ones based on the updated entities. "senior engineer" (ent-2) becomes orphaned — no memory references it anymore. Orphaned entities can be cleaned up by Reflect or Forget.

Why this matters for recall
Query: "what do I know about my work?"
• Vector search finds mem-1, mem-2 (mention work/Acme directly)
• Graph traversal: mem-1 → Acme Corp → mem-3 → Clojure → mem-4
• mem-4 ("learning Clojure for a side project") surfaced through the graph — vector search alone would never find it for a "work" query because it's about a personal project.

The entity is the bridge. No relationship prompt needed. No extra LLM call. Just shared entity resolution.
